# BlockForgeUltimate

BlockForgeUltimate is a React starter dashboard. Its current data is simulated in the browser and no wallet, blockchain, API, or persistent backend is connected.

## Install and run

```bash
git clone https://github.com/centxyz/BlockForgeUltimate.git
cd BlockForgeUltimate
npm install
npm start
```

## Build and test

```bash
npm run build
npm test -- --watchAll=false
```
